## 🔧 故障排查

### 问题1: 导入错误

```bash
❌ 无法导入采集器: No module named 'requests'
```

**解决**:
```bash
source .venv/bin/activate
pip install requests beautifulsoup4 lxml
```

### 问题2: Rust服务不可用

```
Rust服务: ❌ 不可用
```

**解决** (可选):
```bash
cd core-rust/corn-python
source ../../.venv/bin/activate
PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1 maturin develop --release
```
