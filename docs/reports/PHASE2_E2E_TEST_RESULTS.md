## 发现的Bug清单

### P0 (Critical) - 2个

#### Bug #1: Feedtrade采集器缺失
- **严重程度**: P0
- **类别**: Missing Feature
- **描述**: Feedtrade采集器未实现或未注册
- **错误**: "Unknown collector: feedtrade"
- **影响**: 完全无法使用Feedtrade数据源
- **建议**: 
  1. 实现Feedtrade采集器脚本
  2. 在collectors配置中注册
  3. 添加对应的adapter配置

#### Bug #2: 100ppi采集器缺失
- **严重程度**: P0
- **类别**: Missing Feature
- **描述**: 100ppi采集器未实现或未注册
- **错误**: "Unknown collector: 100ppi"
- **影响**: 完全无法使用100ppi数据源
- **建议**:
  1. 实现100ppi采集器脚本
  2. 在collectors配置中注册
  3. 添加对应的adapter配置

### P1 (High) - 2个

#### Bug #3: Boyar采集器并发锁未释放
- **严重程度**: P1
- **类别**: Concurrency
- **描述**: Boyar增量采集进程锁未正确释放
- **错误**: "RuntimeError: Another Boyar incremental collection is running"
- **影响**: Boyar采集器无法启动新的采集任务
- **根因**: 之前的采集进程可能崩溃或超时，但锁未释放
- **建议**:
  1. 实现进程锁超时机制
  2. 添加强制解锁API
  3. 在进程启动前检查并清理僵尸锁
  4. 使用分布式锁（Redis）替代本地锁

#### Bug #4: Job查询API返回空
- **严重程度**: P1
- **类别**: API
- **描述**: GET /api/jobs 返回空结果
- **影响**: 无法通过API查询Job状态
- **建议**:
  1. 验证API实现是否正确
  2. 检查Job数据存储位置
  3. 确认Job与async_jobs表的关系

### P2 (Medium) - 1个

#### Bug #5: DCE采集器配置问题
- **严重程度**: P2
- **类别**: Configuration
- **描述**: DCE采集器需要通过adapter ID调用
- **错误**: "Collector dce requires exactly one configured adapter"
- **影响**: 无法通过collector名称直接调用
- **建议**:
  1. 为DCE配置默认adapter
  2. 或更新API文档说明需要使用adapter ID
  3. 考虑支持通过collector名称自动选择唯一adapter
