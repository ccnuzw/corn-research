```
□ 1.4 安装sea-orm-cli
  cargo install sea-orm-cli

□ 1.5 生成数据库实体
  sea-orm-cli generate entity \
    -u $DATABASE_URL \
    -o core-rust/corn-infrastructure/src/entities

□ 1.6 迁移Repository到SeaORM
  - 修改postgres_repo.rs
  - 替换sqlx查询为SeaORM
  - 测试CRUD操作

□ 1.7 端到端测试
  - Python采集器 → Rust → SeaORM → PostgreSQL
```
