## 项目概述

玉米研究系统V2是一个企业级大宗商品研究管理平台，专注于玉米市场数据的采集、质量评估、标准化存储和可视化分析。

### 核心价值

1. **自动化数据采集**: 多源数据自动采集，节省80%+人工时间
2. **智能质量评估**: 四级评分体系，确保数据可靠性
3. **完整数据血统**: 从原始数据到标准数据的完整追溯
4. **企业级架构**: 高性能、可扩展、生产就绪

## 核心功能

### 1. 数据采集系统

**特性**:
- 多数据源支持（博亚和讯、新浪财经）
- 增量采集（Redis游标管理）
- 限速保护（1.5秒/请求）
- 智能重试（3次，指数退避）
- HTML完整存档（gzip压缩）
- Mock数据兜底

**采集流程**:
```
数据源 → 限速控制 → HTML存档 → 数据解析 → RAW层存储 → 更新游标
```

### 2. 数据质量体系

**四级评分体系**:
- **A级（90-100分）**: 官方数据，完整准确，可直接使用
- **B级（80-89分）**: 商业数据，基本可靠，推荐使用
- **C级（70-79分）**: 媒体数据，需要验证，谨慎使用
- **D级（<70分）**: 数据有问题，不建议使用

**评分维度**:
1. 来源可信度（60%）
2. 数据完整性（20%）
3. 合理性检查（15%）
4. 时效性（5%）

### 3. 数据标准化

**两层存储架构**:
- **RAW层**: 保留原始数据，完整性
- **STANDARD层**: 标准化格式，质量评分

**自动晋升机制**:
- B级以上自动晋升到STANDARD层
- 避免重复转换
- 支持手动触发

### 4. 数据血统追溯

**完整追溯链路**:
```
原始URL → 采集时间 → 采集器 → RAW记录 → 
标准化时间 → 质量评分 → STANDARD记录 → HTML存档路径
```

### 5. API服务

**20个核心端点**:
- 健康检查: 1个
- 采集器管理: 3个
- 数据查询: 7个
- 质量评估: 3个
- 血统追溯: 2个
- 缓存管理: 3个
- 系统监控: 1个

**性能指标**:
- 响应时间: <200ms (P95)
- 缓存命中率: >80%
- 并发支持: 50+用户
