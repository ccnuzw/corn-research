## 🔄 数据流向

### 1. 定时采集流程
```
定时任务触发 (每天8:00)
    ↓
JobManager → CollectionOrchestrator
    ↓
PyO3Bridge → Python采集器 (BoyarV2)
    ↓
HTTP请求 → 博亚和讯网站
    ↓
HTML解析 → RawDataRecord
    ↓
Rust接收 → 数据验证
    ↓
SeaORM → PostgreSQL (RAW层)
    ↓
Redis Pub/Sub → 发布通知 "采集完成"
    ↓
WebSocket → 前端实时显示
```

### 2. 手动触发流程
```
前端点击"运行采集器"按钮
    ↓
POST /api/collectors/run
    ↓
CollectionOrchestrator.run()
    ↓
（同上定时采集流程）
```

### 3. 查询数据流程
```
前端请求最新数据
    ↓
GET /api/data/latest?indicator=山东到车&days=30
    ↓
检查Redis缓存
    ├─ 命中 → 直接返回
    └─ 未命中 ↓
SeaORM查询PostgreSQL
    ↓
写入Redis缓存（5分钟）
    ↓
返回JSON给前端
```

### 4. 实时通知流程
```
后台事件发生（采集完成/失败/异常）
    ↓
NotificationService.publish()
    ↓
Redis Pub/Sub
    ↓
WebSocket服务订阅
    ↓
推送到所有连接的前端
    ↓
前端显示Toast通知
```

## 📦 技术栈总览

### 前端（Next.js）
```
- Next.js 14
- TypeScript
- Shadcn/ui
- TailwindCSS
- WebSocket客户端
```

### 后端（Rust）
```
核心框架：
- Axum 0.7
- Tokio 1.35
- PyO3 0.20

核心依赖：
- sea-orm 0.12       (ORM)
- thiserror 1.0      (错误处理)
- tracing 0.1        (日志)
- dotenvy 0.15       (环境变量)
- redis 0.24         (缓存+Pub/Sub)
- tokio-cron-scheduler 0.9 (定时任务)
```

### 采集器（Python）
```
- Python 3.11
- requests
- beautifulsoup4
- lxml
```

### 数据存储
```
- PostgreSQL 16
- TimescaleDB
- Redis 7
```
